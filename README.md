# Blender-Works

本仓库主要用于 **Blender 学习与实践**，为 Unity 项目创建和准备3D模型资源。

## 📖 仓库说明

- **主要用途**：Blender 软件的学习与建模练习
- **目标应用**：为 Unity 项目提供建模资源
- **开发模式**：个人练习与技能提升

## 🌿 分支管理

### 开发流程
- **主要开发分支**：`dev` 分支（由我本人维护）
- **协作方式**：如有朋友参与，请创建**含义明确的分支名称**
- **合并请求**：需要合并时请联系我进行代码审查

### 分支命名规范
请使用清晰易懂的分支名称，例如：
- `feature/character-modeling`（功能分支）
- `fix/texture-issue`（修复分支）
- `experiment/new-shader`（实验性分支）

## ⚠️ 注意事项

Main 分支将保留用于稳定且有实际应用价值的版本。当前开发内容需经过充分测试和评估后，才会考虑合并至 Main 分支。
